1. Open **Settings › Install** and follow **Open a test page with the widget**.
2. Ask something one of your articles answers. The agent should reply from it.
3. Open the **Inbox** in another tab. Your chat is there, with the AI's reply.
4. In the widget, ask for a person. The chat is now marked **Needs a person**.
5. Reply from the inbox. The answer shows up in the widget.
6. Press **Hand back to AI** when you are done.

## What to try before going live

- **A question nothing covers.** The agent should say it doesn't know and offer a person, not guess.
- **A question that needs live data,** if you connected [tools](tools.md).
- **Each important rule.** Write a message that should match it.
- **Your own site on a phone.** Check that the button covers nothing important.

> [!TIP]
> When an answer is wrong, first ask where the right one is written down. Most fixes are a clearer article, not a longer instruction.
